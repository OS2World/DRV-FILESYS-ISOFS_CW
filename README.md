DRV-ISOFS
=========

> **Superseded.** This repository is the original ISOFS 0.2.1 by Chris Wohlgemuth (2001), kept as it was. ISOFS was rewritten and has been maintained since 2004 by Paul Ratcliffe (with updates by Rich Walsh): the maintained version is **[DRV-FILESYS-ISOFS](https://github.com/OS2World/DRV-FILESYS-ISOFS)**.

ISO installable File System for OS/2 to access ISO rawfiles suitable for burning on CD.
